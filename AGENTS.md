# AGENTS.md

Go 1.23 Gin REST API backed by PostgreSQL. Setup, scripts, linting, and hooks are
documented in `README.md`; endpoint details live in `docs/API.md`.

## Commands

- `make test` — all tests; no database required (repositories are mocked).
- `go test ./internal/service -run TestCreate_Success -count=1` — run one test/package.
- `make check` — `go vet` + golangci-lint + tests; run before finishing changes.
- `make lint` / `make lint-fix` / `make fmt` — lint and format using `.golangci.yml`
  (golangci-lint v2; falls back to a pinned `go run` if the binary is absent).
- `make hooks` — one-time local install of `.githooks/pre-commit` via `core.hooksPath`.
- `make run` — starts the API; requires PostgreSQL (`docker compose up -d postgres`).
- `make swagger` — regenerate `docs/` after changing routes or handler annotations.

## Architecture

- Wiring: `cmd/api/main.go` → `handler.NewRouter` → `TripHandler` → `TripService` →
  `TripRepository` (pgx). The repository interface lives in `internal/service`.
- `internal/service` maps repository sentinels (`ErrNotFound`, `ErrTripNumberConflict`,
  `ErrIdempotencyConflict`) to `*httperr.AppError`. Keep mapping there; handlers only
  call `writeError`.
- `internal/domain/status.go` is the source of truth for transitions, but the same
  states are enforced by a SQL `CHECK` in `migrations/000001_create_trips.up.sql`.
  Change both together (and regenerate Swagger enums).
- Idempotent creates are transactional: `CreateWithIdempotency` stores the response
  body in `idempotency_keys`. Replays return `200`; same key with a different request
  hash returns `409`. Keep `service.hashCreateRequest` canonicalization stable or
  existing keys will look reused.
- Status updates lock the row with `SELECT ... FOR UPDATE` and increment `version`.
  Same-status `PATCH` is an intentional no-op returning `200`.
- Migrations run automatically on boot (`database.RunMigrations`); `make migrate-up`
  is optional. Docker copies `migrations/` to `/app/migrations`.

## Gotchas

- `DATABASE_URL` is required to boot the server, but not to run tests.
- Default local DB: `postgres://trip:trip@localhost:5432/tripdb?sslmode=disable`.
- `docs/docs.go` is generated by `swag@latest`; do not hand-edit. Regeneration may
  produce unrelated diffs from a newer generator.
- The pre-commit hook skips when no `.go` files are staged, but otherwise runs
  vet/lint/tests repo-wide. Use `--no-verify` only deliberately.
- Module path is `github.com/iamadarsh0309/Trip-API` (capital `API`); match it in
  imports and Swagger annotations.
- CI pins golangci-lint `v2.15.0`; keep `.golangci.yml` on config `version: "2"`.
- Without a local golangci-lint binary, `make lint` uses `go run` and may
  auto-download Go 1.26 (v2.15 needs it) despite the project targeting Go 1.23.
